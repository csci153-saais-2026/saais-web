POST /functions/v1/students/{student_id}/record-grades

recordGrades

Records grades for a current advisee. A prerequisite override requires a reason and is audited.

bearerAuth · Role: adviser · Contract v0.3.0

Request body

FieldRequiredPurpose
school_term_idYesSchool term
course_offering_idYesCourse offering
midterm_grade, final_grade, instructorNoGrade and instructor details
continue_with_prerequisite_overrideNoConfirm prerequisite override
prerequisite_override_reasonConditionalRequired when override is true

Responses

200 Recorded · 400 Invalid input · 403 Not the current adviser · 409 Prerequisite not met without override, term locked, or grade already recorded.

Example error

{ "code": "PREREQUISITE_NOT_MET", "message": "Strict prerequisite not satisfied", "details": "CSci 132 requires CSci 121 (strict)", "hint": "Resubmit with continue_with_prerequisite_override and a reason" }
