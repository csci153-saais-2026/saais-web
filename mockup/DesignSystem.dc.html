Status vocabulary

PassedFailedINCINC lapsedEnrolledDroppedNo attendanceNot taken

Every badge carries a text label as well as a color, and each pairs a dot with the word — color is never the only channel. INC and INC lapsed are deliberately distinct: a lapsed INC keeps the status it was given and is only evaluated as 5.00.

Contrast
All badge text clears 4.5:1 on its own ground.
Focus ring
2px forest outline, 2px offset, on every interactive element.
Hit target
44px minimum on touch surfaces.
Screen readers
Status is announced as text, not as a color name.

Buttons and controls

Gold is used for exactly one button in the product: Continue with override. Nothing else competes with it.

Search
Advisory — an exception the adviser should read before continuing.
Confirmed — the invariant held and the write is safe.
Blocked — the request was refused by a policy or a lock.
