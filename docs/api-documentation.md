# API & Developer Documentation Guide

SAAIS maintains a single canonical OpenAPI 3.1 contract and exposes it through two synchronized surfaces: an in-app interactive reference for active contributors and a standalone static HTML bundle built in Continuous Integration (CI).

## Canonical Source of Truth

| Artifact | Location | Role |
| --- | --- | --- |
| OpenAPI 3.1 Specification | `contract/openapi.yaml` | Single hand-authored source of truth for PostgREST projections, Edge Functions, schemas, and role metadata |
| Redocly Configuration | `contract/redocly.yaml` | Linting rules and static documentation build settings |
| Generated TypeScript Types | `contract/generated/schema.d.ts` | Auto-generated types consumed by `src/lib/api` (`npm run contract:gen`) |
| Static Redoc Bundle | `docs/openapi/index.html` | Self-contained HTML bundle generated by `npm run contract:docs` and uploaded in CI |

Neither `/docs/openapi` nor CI maintains a second copy of `contract/openapi.yaml`. In the Vite application, `src/routes/docs/OpenApiDocsPage.tsx` imports `contract/openapi.yaml?url` directly:

- During `npm run dev`, Vite serves `contract/openapi.yaml` live from disk so edits appear on browser refresh.
- During `npm run build`, Vite emits `contract/openapi.yaml` as a content-hashed static asset under `dist/assets/` so the production bundle always matches the exact commit it was built from.

## In-App Documentation Routes

| Route | Purpose | Access Policy |
| --- | --- | --- |
| `/docs` | Curated developer documentation hub rendering explicitly allowlisted guides from `docs/` plus navigation to `/docs/openapi` and `/styleguide` | Open in local development (`import.meta.env.DEV`); requires an authenticated SAAIS session in non-development builds |
| `/docs/openapi` | Interactive Redoc API reference bound directly to `contract/openapi.yaml` | Open in local development (`import.meta.env.DEV`); requires an authenticated SAAIS session in non-development builds |
| `/styleguide` | Live SAAIS design tokens and UI component catalog | In-app reference route |

### Authentication Policy Outside Development

Access to `/docs` and `/docs/openapi` is enforced by `DocsAuthGate` (`src/routes/docs/DocsAuthGate.tsx`):

1. **Development (`npm run dev`)**: `import.meta.env.DEV` is `true`, so `/docs` and `/docs/openapi` render immediately without requiring sign-in.
2. **Production & Preview (`npm run build && npm run preview` or deployed hosts)**: `import.meta.env.DEV` is `false`, so `DocsAuthGate` verifies an active user access token via `resolveCurrentAccessToken()` (`src/lib/api/auth-token.ts`) before mounting documentation content or loading Redoc. Unauthenticated visitors receive an advisory prompt directing them to sign in.

### Explicit Allowlist for Repository Guides

The `/docs` hub never uses wildcard directory globs over `docs/`. Internal artifacts such as `docs/meeting-minutes/` remain repository-only unless explicitly registered in `src/routes/docs/docs-registry.ts` via static `?raw` imports.

## Running & Updating API Documentation Locally

Run the local Vite server to browse `/docs` and `/docs/openapi` interactively:

```bash
npm run dev
```

After editing `contract/openapi.yaml`, run the full contract validation and regeneration workflow before committing:

```bash
# 1. Lint the OpenAPI 3.1 contract against contract/redocly.yaml
npm run contract:lint

# 2. Run contract security and role-boundary invariants
npm run contract:security

# 3. Regenerate TypeScript types in contract/generated/schema.d.ts
npm run contract:gen

# 4. Verify generated schema types have zero git drift
npm run contract:check

# 5. Build the standalone static Redoc HTML bundle
npm run contract:docs
```

## CI Static Bundle & Build Artifact

In `.github/workflows/ci.yml` (`Lint & Build` job), GitHub Actions validates and publishes the static Redoc documentation on every push and pull request:

1. Runs `npm run contract:lint`, `npm run contract:security`, and `npm run contract:check` against `contract/openapi.yaml`.
2. Builds the static HTML bundle via `npm run contract:docs`, producing `docs/openapi/index.html` from the canonical `contract/openapi.yaml` specification.
3. Verifies that `docs/openapi/index.html` exists and is non-empty, failing the workflow with an explicit error annotation if generation fails.
4. Publishes `docs/openapi/index.html` using `actions/upload-artifact@v4`:
   - **Artifact Name**: `openapi-redoc-bundle`
   - **Artifact Source Path**: `docs/openapi/index.html`
   - **Retention**: 14 days

Reviewers can download `openapi-redoc-bundle` from the GitHub Actions run summary and open `index.html` directly in any browser without running Node.js or Vite locally.
